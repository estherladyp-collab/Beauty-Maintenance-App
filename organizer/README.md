# Maintaining Home

Kalender, To-dos (Victory Family, Church mit VOMI/GLS/Choir, Home) und der Haushaltsplaner aus dem PDF: Kochplan mit 4-Wochen-Rotation, Einkauf, Vorräte, Reinigung, Budget.

Starten: `python3 -m http.server` in diesem Ordner, dann `http://localhost:8000` öffnen. Auf dem Handy über HTTPS hosten und "Zum Home-Bildschirm" wählen. Alles wird auf dem Gerät gespeichert, Backup unter Mehr.

Dateien: `seed.js` (Daten aus dem PDF), `store.js` (Speicher), `app.js` (Oberfläche), `styles.css`, `sw.js` (offline).
